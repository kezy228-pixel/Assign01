# Grocery Management System (CS3354 Assignment 1)

## Overview

A console-based grocery inventory management system utilizing parallel arrays to manage item names, prices, and stock levels.

## Features

- **View Inventory:** Displays all non-empty inventory slots.
- **Restock Item:** Searches for an item and adds to its stock.
- **Interactive Menu:** Continuous loop for user interaction.

## How to Run

1. Compile the Java file:
   ```bash
   javac GroceryManagementSystem.java
   ```
